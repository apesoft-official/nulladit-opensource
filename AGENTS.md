# NOMC contributor instructions
Read and follow [CONSTITUTION.md](CONSTITUTION.md) before modifying or publishing code. Stop if a change requires private source, secrets, undocumented privileged interfaces or unverified network configuration. Do not weaken release gates.

For every relevant engineering sweep, execute the constitution's mandatory dual-target maintenance checklist: updated device client installers AND independently deployable websites/apps. Report evidence or blockers for both; do not certify completion on documentation alone.
